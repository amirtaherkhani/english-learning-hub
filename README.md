# English Learning Hub

A Persian-first, modular English learning knowledge base.

- [Golden Rules](golden-rules/README.md): numbered, topic-organized grammar rules with Persian mnemonics and real-life examples.
- [Basic Grammar in Use — 4th edition](grammar-in-use/basic/edition-04/README.md): an edition-scoped home for independently authored notes and future lessons.

Each learning module owns its `lessons/`, `skills/`, `docs/`, `vocabulary/`, and `practice/` directories. Vocabulary and practice directories are documentation-only placeholders: live questions, answers, and scores are never committed.

The Golden Rules Trainer is designed for native ChatGPT interactive exercises, with 3 preloaded sets, percentage scoring, Reset, Next, and New controls. No external exercise service is required.
