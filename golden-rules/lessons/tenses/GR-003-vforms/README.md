# GR-003 — V1 / V2 / V3

- **Category:** tenses
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> گذشته خبری V2؛ بعد از did شکل V1؛ بعد از have یا مجهول شکل V3

## فرمول

`go/went/gone; write/wrote/written; finish/finished/finished`

## مثال‌های واقعی

- **I went.** — رفتم.
- **Did you go?** — رفتی؟
- **I've gone.** — رفته‌ام.
- **It was written.** — نوشته شد.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
