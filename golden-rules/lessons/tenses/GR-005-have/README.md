# GR-005 — کاربردهای HAVE

- **Category:** tenses
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> مالکیت → have؛ انجام داده‌ام → have+V3؛ حالت روحی اغلب be+adjective

## فرمول

`have/has + noun; have/has + V3; had + V3`

## مثال‌های واقعی

- **I have a car.** — ماشین دارم.
- **I'm stressed.** — استرس دارم.
- **I've eaten.** — غذا خورده‌ام.
- **I'd had breakfast.** — صبحانه خورده بودم.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
