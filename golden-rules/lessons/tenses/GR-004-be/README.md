# GR-004 — قانون BE

- **Category:** tenses
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> وضعیت و بودن → BE؛ تغییر وضعیت → GET/BECOME

## فرمول

`am/is/are; was/were; will be; has/have been`

## مثال‌های واقعی

- **I'm tired.** — خسته‌ام.
- **I was busy.** — سرم شلوغ بود.
- **I'll be ready.** — آماده می‌شوم.
- **She has been ill.** — بیمار بوده است.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.

## Deep dive — BE vs GET / BECOME, active, passive, and continuous

### Persian decision code

| فارسی | Pattern | Example |
|---|---|---|
| هستم / بودم | be + state | I'm tired. / I was tired. |
| خسته شدم | get/become + adjective | I got tired. |
| دارم کار می‌کنم | be + V-ing | I'm working. |
| تمیز شد | be + V3 (passive) | It was cleaned. |
| دارد تمیز می‌شود | be + being + V3 | It's being cleaned. |
| تمیز شده است | have/has + been + V3 | It has been cleaned. |
| خواهد شد | will + be + V3 | It will be done. |
| باید انجام شود | modal + be + V3 | It must be done. |

### BE conjugation

| Time | Forms | Example |
|---|---|---|
| Present | am/is/are | I am ready. |
| Past | was/were | I was ready. |
| Future | will be | I will be ready. |
| Present perfect | have/has been | I have been ready since noon. |
| Past perfect | had been | I had been ready for hours before they arrived. |
| Modal | modal + be | I might be late. |

### BE as a main verb (state, identity, location)

- **I'm tired.** — خسته‌ام.
- **She is an engineer.** — او مهندس است.
- **We're at home.** — خانه هستیم.
- **I'll be ready tomorrow.** — فردا آماده خواهم بود.

### BE as an auxiliary

- **I'm cleaning the house.** — دارم خانه را تمیز می‌کنم. (active continuous)
- **The house is cleaned every week.** — خانه هر هفته تمیز می‌شود. (simple passive)
- **The house is being cleaned.** — خانه دارد تمیز می‌شود. (continuous passive)
- **The house has been cleaned.** — خانه تمیز شده است. (perfect passive)
- **The house will be cleaned.** — خانه تمیز خواهد شد. (future passive)

### Modal + BE and TO BE

- **I will work.** — کار خواهم کرد.
- **I will be working.** — در حال کار خواهم بود.
- **I will be ready.** — آماده خواهم بود.
- **It must be repaired.** — باید تعمیر شود.
- **I want to be ready.** — می‌خواهم آماده باشم.
- **I need to be there.** — لازم است آنجا باشم.
- **I want to work.** — می‌خواهم کار کنم؛ بدون be.

### When BE is not used

| Incorrect | Correct | Why |
|---|---|---|
| I am work every day. | I work every day. | Present simple active action. |
| I was went home. | I went home. | Past simple active action. |
| I will be go. | I will go. | Future simple active action. |
| Did you be tired? | Were you tired? | BE questions invert subject and verb. |
| I am understand. | I understand. | Understand is ordinarily stative. |
| I have be finished. | I have finished. | Present perfect active is have + V3. |

### The three meanings of BEEN

- **I've been sick.** — مریض بوده‌ام: have been + state.
- **I've been working.** — مدتی است کار می‌کنم: have been + V-ing.
- **It has been repaired.** — تعمیر شده است: has been + V3 (passive).

### Contrast: BE vs GET / BECOME

- **I'm tired.** — خسته‌ام (state).
- **I got tired.** — خسته شدم (change).
- **She is rich.** — او پولدار است.
- **She became rich.** — او پولدار شد.
- **It is cold.** — هوا سرد است.
- **It got cold.** — هوا سرد شد.

### Five-second memory code

> **حالت = BE؛ تغییر حالت = GET/BECOME؛ در جریان = BE + V-ing؛ مجهول = BE + V3؛ انجام شدهٔ مجهول = HAVE BEEN + V3.**
