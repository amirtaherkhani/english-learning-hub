# GR-004 — قانون BE

- **Category:** tenses
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> وضعیت و بودن → BE؛ تغییر وضعیت → GET/BECOME

## فرمول

`am/is/are; was/were; will be; has/have been`

## مثال‌های واقعی

- **I'm tired.** — خسته‌ام.
- **I was busy.** — سرم شلوغ بود.
- **I'll be ready.** — آماده می‌شوم.
- **She has been ill.** — بیمار بوده است.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
