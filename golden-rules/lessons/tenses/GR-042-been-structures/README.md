# GR-042 — HAS BEEN STRUCTURES

**Category:** tenses

## قانون طلایی و کد فارسی

> been+صفت → بوده؛ been+V3 → مجهول شده؛ been+V-ing → مدتی است دارد؛ تغییر حالت → become

## مثال‌های واقعی

- **Sara has been rich.** — سارا پولدار بوده.
- **Sara has become rich.** — سارا پولدار شده.
- **The house has been cleaned.** — خانه تمیز شده است.
- **She has been working.** — مدتی است دارد کار می‌کند.

## نکات

- فعل کمکی و ساختار جمله تعیین می‌کنند فعل اصلی V1، V2، V3 یا V-ing باشد.
- مثال‌ها را در بافت روزمره یاد بگیر؛ معادل‌های فارسی همیشه یک‌به‌یک نیستند.
- سؤال‌ها و نتایج تمرین صرفاً در چت ساخته و نمایش داده می‌شوند.
