# GR-006 — مجهول

- **Category:** tenses
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> انجام شدن روی چیزی → BE + V3؛ در حال انجام → BEING؛ انجام شده → BEEN

## فرمول

`is cleaned; was cleaned; is being cleaned; has been cleaned; will be cleaned`

## مثال‌های واقعی

- **The house is cleaned.** — خانه تمیز می‌شود.
- **The house was cleaned.** — خانه تمیز شد.
- **The house is being cleaned.** — خانه دارد تمیز می‌شود.
- **The house has been cleaned.** — خانه تمیز شده است.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
