# GR-008 — شد / شده / بوده

- **Category:** tenses
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> تغییر حالت → become/get؛ وضعیت موجود → be؛ کار انجام‌شده → passive

## فرمول

`became/got + adjective; has become + adjective; has been + adjective`

## مثال‌های واقعی

- **Sara became rich.** — سارا پولدار شد.
- **Sara has become rich.** — سارا پولدار شده است.
- **Sara has been rich.** — سارا پولدار بوده است.
- **It got cold.** — هوا سرد شد.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
