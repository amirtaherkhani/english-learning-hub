# GR-013 — جملات شرطی IF

- **Category:** conditionals
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> آیندهٔ ممکن: if+حال، will؛ خیال حال: if+گذشته، would؛ حسرت: if+had V3، would have V3

## فرمول

`If+present, will+V1; If+past, would+V1; If+had+V3, would have+V3`

## مثال‌های واقعی

- **If I have time, I'll call.** — اگر وقت داشته باشم زنگ می‌زنم.
- **If I had time, I'd call.** — اگر وقت داشتم زنگ می‌زدم.
- **If I'd known, I'd have called.** — اگر می‌دانستم زنگ زده بودم.
- **If you heat ice, it melts.** — اگر یخ را گرم کنی آب می‌شود.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
