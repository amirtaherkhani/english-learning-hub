# GR-025 — NOW / YET / STILL / ALREADY / JUST

**Category:** time-expressions

## قانون طلایی — کد فارسی

> هنوز ادامه دارد → still؛ هنوز انجام نشده → yet؛ دیگه انجام شده → already؛ تازه → just

## مثال‌های روزمره

- **I'm still working.** — هنوز کار می‌کنم.
- **I haven't eaten yet.** — هنوز غذا نخورده‌ام.
- **I've already eaten.** — دیگه غذا خورده‌ام.
- **I've just arrived.** — تازه رسیده‌ام.

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## Deep dive — STILL (2026-10-11)

### Persian mnemonic

> **STILL = هنوز / همچنان**: وضعیتی که قبلاً وجود داشته و حالا هم ادامه دارد.

### Placement

| Context | Pattern | Example |
|---|---|---|
| Main verb | subject + still + verb | I still live here. |
| BE | subject + be + still | I'm still tired. |
| Continuous | subject + be + still + V-ing | I'm still waiting. |
| Modal | subject + modal + still + V1 | I can still help. |
| Negative perfect | subject + still + haven't/hasn't + V3 | I still haven't finished. |

### STILL vs YET vs ALREADY

- **I'm still working.** — هنوز دارم کار می‌کنم؛ ادامهٔ فعالیت.
- **I haven't finished yet.** — هنوز تمام نکرده‌ام؛ رویداد تکمیل هنوز رخ نداده.
- **I still haven't finished.** — هنوز هم تمام نکرده‌ام؛ تأکید روی ادامهٔ انجام‌نشدن.
- **I've already finished.** — دیگه تمام کرده‌ام.

### Opposite: NO LONGER / ANYMORE

- **I still work here.** — هنوز اینجا کار می‌کنم.
- **I don't work here anymore.** — دیگه اینجا کار نمی‌کنم.
- **I no longer work here.** — دیگر اینجا کار نمی‌کنم (رسمی‌تر).

### Common mistakes

- ❌ I am working still now. → Prefer **I'm still working.**
- ❌ I still am work. → **I'm still working.**
- ❌ I haven't still finished. → Prefer **I still haven't finished.** or **I haven't finished yet.**

### Five-second recap

> هنوز ادامه دارد → STILL؛ هنوز اتفاق نیفتاده → NOT YET؛ هنوز هم اتفاق نیفتاده → STILL NOT؛ دیگر نه → NOT ANYMORE.
