# GR-026 — SINCE / SINCE THEN / FOR

**Category:** time-expressions

## قانون طلایی — کد فارسی

> نقطهٔ شروع → since؛ مدت → for؛ از آن موقع تا الان → since then

## مثال‌های روزمره

- **I've worked here since 2020.** — از ۲۰۲۰ اینجا کار می‌کنم.
- **I've been waiting for an hour.** — یک ساعت است منتظرم.
- **I haven't seen him since then.** — از آن موقع ندیدمش.
- **Everything has been fine so far.** — تا الان همه‌چیز خوب بوده.

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## تمرین زنده

تمرین، پاسخ و نمره در مخزن ذخیره نمی‌شوند؛ Skill مربوطه آن‌ها را داخل چت تولید می‌کند.
