# GR-010 — دو مودال کنار هم

- **Category:** modal-verbs
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> دو مودال اصلی پشت سر هم نمی‌آیند؛ یکی را جایگزین کن

## فرمول

`will be able to; might have to; should be able to`

## مثال‌های واقعی

- **I'll be able to come.** — خواهم توانست بیایم.
- **I might have to leave.** — شاید مجبور شوم بروم.
- **You should be able to do it.** — باید بتوانی انجامش بدهی.
- **She may be allowed to enter.** — شاید اجازهٔ ورود داشته باشد.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
