# GR-009 — افعال مودال

- **Category:** modal-verbs
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> بعد از مودال فعل ساده؛ برای گذشتهٔ فرضی modal+have+V3

## فرمول

`can/could/may/might/must/should/will/would + V1`

## مثال‌های واقعی

- **I can help.** — می‌توانم کمک کنم.
- **You should rest.** — بهتر است استراحت کنی.
- **He might come.** — شاید بیاید.
- **You should have called.** — بهتر بود زنگ می‌زدی.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
