# GR-041 — MODAL QUESTIONS

**Category:** modal-verbs

## قانون طلایی و کد فارسی

> سؤال مودال → Modal + subject + V1?؛ گذشتهٔ فرضی → Modal + subject + have + V3?

## مثال‌های واقعی

- **Could you come?** — می‌توانستی/می‌شود بیایی؟
- **Should I leave?** — بهتر است بروم؟
- **Could you have called?** — می‌توانستی زنگ بزنی؟
- **Would you help me?** — کمکم می‌کردی/می‌شود کمک کنی؟

## نکات

- فعل کمکی و ساختار جمله تعیین می‌کنند فعل اصلی V1، V2، V3 یا V-ing باشد.
- مثال‌ها را در بافت روزمره یاد بگیر؛ معادل‌های فارسی همیشه یک‌به‌یک نیستند.
- سؤال‌ها و نتایج تمرین صرفاً در چت ساخته و نمایش داده می‌شوند.
