# GR-012 — WILL در برابر WOULD

- **Category:** modal-verbs
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> می‌کنم → will؛ می‌کردم اگر... → would؛ می‌کردم ولی نشد → would have+V3

## فرمول

`will+V1; would+V1; would have+V3`

## مثال‌های واقعی

- **I'll tell you.** — بهت می‌گویم.
- **I'd tell you if I knew.** — اگر می‌دانستم بهت می‌گفتم.
- **I would've told you.** — بهت می‌گفتم ولی نشد.
- **She said she would come.** — گفت می‌آید.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
