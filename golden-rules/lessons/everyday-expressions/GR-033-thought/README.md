# GR-033 — THINK / THOUGHT

**Category:** everyday-expressions

## قانون طلایی — کد فارسی

> think → thought → thought؛ فکر می‌کردم → I thought؛ در حال بررسی → I'm thinking

## مثال‌های روزمره

- **I think you're right.** — فکر می‌کنم حق با توست.
- **I thought you knew.** — فکر می‌کردم می‌دانستی.
- **I'm thinking about it.** — دارم بهش فکر می‌کنم.
- **Let me think it over.** — بگذار خوب بررسی کنم.

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## تمرین زنده
