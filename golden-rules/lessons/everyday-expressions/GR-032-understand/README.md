# GR-032 — UNDERSTAND AND SYNONYMS

**Category:** everyday-expressions

## قانون طلایی — کد فارسی

> فهمیدن مفهوم → understand؛ گرفتم → got it؛ با فکر فهمیدم → figured out؛ تازه فهمیدم → realized

## مثال‌های روزمره

- **I understand.** — می‌فهمم.
- **Got it!** — گرفتم!
- **I figured it out.** — با فکر راهش را پیدا کردم.
- **I just realized it.** — تازه متوجه شدم.

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## تمرین زنده

تمرین، پاسخ و نمره در مخزن ذخیره نمی‌شوند؛ Skill مربوطه آن‌ها را داخل چت تولید می‌کند.
