# GR-035 — BREAKFAST / LUNCH / DINNER

**Category:** everyday-expressions

## قانون طلایی — کد فارسی

> وعدهٔ غذایی → have breakfast/lunch/dinner؛ غذای مشخص → eat؛ برای وعده → for

## مثال‌های روزمره

- **I had breakfast.** — صبحانه خوردم.
- **Have you had lunch?** — ناهار خورده‌ای؟
- **I eat eggs for breakfast.** — برای صبحانه تخم‌مرغ می‌خورم.
- **What are we having for dinner?** — برای شام چی داریم؟

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## تمرین زنده
