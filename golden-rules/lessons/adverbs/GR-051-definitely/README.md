# GR-051 — DEFINITELY: «قطعاً»، با اطمینان بالا

- **English title:** Definitely
- **Catalog category:** adverbs
- **Grammar category:** adverb of certainty / short response
- **Core level:** B1
- **Difficulty:** Normal
- **هدف:** بیان اطمینان قوی و تشخیص تفاوت **definitely** با **probably** و **maybe**.

## قانون طلایی

**Definitely** یعنی «قطعاً / حتماً / بدون شک» و نشان می‌دهد گوینده دربارهٔ گفته‌اش اطمینان زیادی دارد. این واژه میزان اطمینان گوینده را بیان می‌کند؛ به‌تنهایی مدرک یا تضمین واقعی نمی‌سازد. [Cambridge Dictionary: Definitely](https://dictionary.cambridge.org/dictionary/english/definitely)

## جایگاه و فرمول

- پیش از فعل اصلی: **فاعل + definitely + فعل اصلی**
- پس از **be**: **فاعل + be + definitely + ادامه**
- پس از مودال/فعل کمکی: **فاعل + will/can/have + definitely + فعل/قسمت بعد**
- برای تأکید: **Definitely!** به‌عنوان پاسخ مستقل
- برای نفی قاطع: **definitely not** یا **فاعل + definitely + فعل منفی**

## کاربردها و مثال‌ها

- **I definitely need a new charger.** — قطعاً به شارژر تازه‌ای نیاز دارم.
- **She's definitely the right person for this job.** — او قطعاً شخص مناسبی برای این کار است.
- **We will definitely call you tomorrow.** — حتماً فردا به تو زنگ می‌زنیم.
- **He has definitely improved.** — او قطعاً پیشرفت کرده است.
- **I'm definitely not staying late tonight.** — قطعاً امشب تا دیروقت نمی‌مانم.
- **Did you definitely send the invoice?** — مطمئنی فاکتور را فرستادی؟
- **A: Do you want to come with us? B: Definitely!** — می‌خواهی با ما بیایی؟ — حتماً!

## تفاوت با واژه‌های نزدیک

- **maybe / perhaps** — ممکن است؛ تعهد و اطمینان پایین‌تر.
- **probably** — به‌احتمال زیاد؛ هنوز حدس است.
- **definitely** — اطمینان بسیار قوی یا پاسخ قاطع.
- **certainly** — معنی نزدیک دارد و در درخواست‌های مؤدبانه یا لحن رسمی‌تر هم رایج است.

## دام‌های رایج

- **definitely** را برای حدسِ نامطمئن به کار نبر؛ آن‌جا **probably** یا **maybe** را انتخاب کن.
- جای معمول منفی: **I definitely don't agree** یا **I will definitely not go**. در گفتار، **definitely not** هم پاسخ طبیعی است.
- املای درست **definitely** است؛ نه **definately**.

## کدگذاری فارسی و قانون پنج‌ثانیه‌ای

- «قطعاً / حتماً / بدون شک» → **definitely**
- «احتمال زیاد، اما نه قطعی» → **probably**
- «امکان نامشخص» → **maybe**

1. **تشخیص:** فقط حدس می‌زنی یا با اطمینان حرف می‌زنی؟
2. **تصمیم:** اطمینان بالا → **definitely**.
3. **اجرا:** قبل از فعل اصلی، پس از **be/کمکی**، یا به‌تنهایی در پاسخ.
4. **بررسی استثنا:** با انتخاب این واژه لحن قطعی می‌شود؛ اگر مطمئن نیستی، ضعیف‌ترش کن.
