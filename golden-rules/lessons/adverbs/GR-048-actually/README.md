# GR-048 — ACTUALLY: «درواقع» برای روشن‌کردن یا اصلاح واقعیت

- **English title:** Actually
- **Catalog category:** adverbs
- **Grammar category:** adverb / sentence adverb / discourse marker
- **Core level:** A2
- **Optional extension:** B1
- **Difficulty:** Normal
- **هدف:** استفاده از **actually** برای بیان واقعیت، اصلاح برداشت یا نشان‌دادن تفاوت با انتظار.

## قانون طلایی

از **actually** وقتی استفاده کن که می‌خواهی بگویی «درواقع/راستش»، اطلاعات واقعی را روشن کنی یا با انتظار قبلی تفاوت نشان بدهی. این کلمه معنی «در حال حاضر» نمی‌دهد؛ برای آن از **currently / right now** استفاده کن.

## جایگاه و فرمول

- ابتدای جمله برای اصلاح یا آوردن واقعیت: **Actually, + جمله**
- پیش از فعل اصلی: **فاعل + actually + فعل اصلی**
- بعد از **be** یا اولین فعل کمکی: **فاعل + be/کمکی + actually + ادامهٔ جمله**
- گاهی در پایان جملهٔ محاوره‌ای برای افزودن اصلاح: **جمله + actually**

## کاربردها و مثال‌ها

### 1. روشن‌کردن واقعیت یا پاسخ متفاوت از انتظار

- **Actually, I live near the station.** — درواقع، نزدیک ایستگاه زندگی می‌کنم.
- **We actually enjoyed the meeting.** — راستش جلسه را واقعاً دوست داشتیم.
- **The café is actually open on Sundays.** — این کافه درواقع یکشنبه‌ها باز است.
- **I didn't actually see him; I only heard his voice.** — درواقع او را ندیدم؛ فقط صدایش را شنیدم.

### 2. اصلاح مؤدبانه یا مخالفت ملایم

- **Actually, the meeting is on Thursday, not Wednesday.** — درواقع جلسه پنج‌شنبه است، نه چهارشنبه.
- **Actually, I'd prefer tea.** — راستش چای را ترجیح می‌دهم.
- **Are you coming tonight? — Actually, I can't.** — امشب می‌آیی؟ — راستش نمی‌توانم.
- **This is my old address, actually.** — راستش این نشانی قبلی من است.

در ابتدای پاسخ می‌تواند اصلاح را نرم‌تر کند، اما با لحن تند ممکن است حالت «نه، اشتباه می‌کنی» بگیرد. [Cambridge Grammar: Actually](https://dictionary.cambridge.org/us/grammar/british-grammar/actually)

## تفاوت با واژه‌های نزدیک

| عبارت | کارکرد |
|---|---|
| **actually** | واقعیت را روشن یا برداشت را اصلاح می‌کند. |
| **really** | شدت می‌دهد («خیلی») یا واقعی‌بودن/جدی‌بودن را می‌پرسد. |
| **currently / right now** | زمان حال را مشخص می‌کند («در حال حاضر»). |
| **in fact** | «درواقع»؛ معمولاً برای افزودن واقعیت یا تأکید، کمی مرتب‌تر از مکالمهٔ خودمانی. |

**Actual** صفت است و پیش از اسم می‌آید؛ **actually** قید است:

- **the actual cost** — هزینهٔ واقعی
- **The cost is actually higher.** — هزینه درواقع بیشتر است.

## دام‌های رایج

- **Actually, I'm working in London.** یعنی «درواقع در لندن کار می‌کنم» و می‌تواند جملهٔ کاملاً درستی باشد؛ اگر فقط منظورت «در حال حاضر» است، **I'm currently working in London.** شفاف‌تر است.
- **Actually** را فقط برای مخالفت به کار نبر؛ برای گفتن واقعیتی تازه هم طبیعی است.
- جای **actually** می‌تواند روی تأکید اثر بگذارد: **I actually called her** یعنی برخلاف انتظار، واقعاً زنگ زدم؛ **I called her, actually** می‌تواند اصلاحی باشد که آخر حرف اضافه می‌شود.

## کدگذاری فارسی و قانون پنج‌ثانیه‌ای

- «درواقع / راستش / برخلاف چیزی که فکر می‌کردیم» → **actually**
- «در حال حاضر» → **currently / right now**
- «خیلی / واقعاً چقدر؟» → **really**

1. **تشخیص:** واقعیت را روشن یا انتظار را اصلاح می‌کنی؟
2. **تصمیم:** بله → **actually**؛ فقط زمان فعلی را می‌گویی → **currently**.
3. **اجرا:** ابتدای جمله برای اصلاح کلی، یا نزدیک فعل/عبارت مورد تأکید.
4. **بررسی استثنا:** اگر مخالفت می‌کنی، لحن را ملایم نگه دار تا بی‌ادبانه شنیده نشود.
