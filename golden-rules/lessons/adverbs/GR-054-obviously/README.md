# GR-054 — OBVIOUSLY: «واضح است که» یا نتیجه‌گیری از نشانه‌ها

- **English title:** Obviously
- **Catalog category:** adverbs
- **Grammar category:** adverb of certainty / evaluative sentence adverb
- **Core level:** B1
- **Difficulty:** Normal
- **هدف:** استفاده از **obviously** برای چیزی که روشن به نظر می‌رسد و توجه به لحن قاطع یا سرزنش‌آمیز آن.

## قانون طلایی

**Obviously** یعنی «واضح است که / آشکارا»؛ می‌گویی چیزی برایت روشن است یا از شواهد به نتیجه‌ای می‌رسی. این واژه از گوینده اطمینان نشان می‌دهد و گاهی ممکن است شنونده را سرزنش کند، انگار «این که معلومه». [Cambridge Dictionary: Obviously](https://dictionary.cambridge.org/dictionary/english/obviously)

## جایگاه و فرمول

- ابتدای جمله برای نظر دربارهٔ کل جمله: **Obviously, + جمله**
- پیش از فعل اصلی: **فاعل + obviously + فعل اصلی**
- پس از **be** یا اولین فعل کمکی: **فاعل + be/کمکی + obviously + ادامه**

## کاربردها و مثال‌ها

- **Obviously, we need to check the figures again.** — واضح است که باید اعداد را دوباره بررسی کنیم.
- **She's obviously tired after the long flight.** — بعد از پرواز طولانی، آشکارا خسته است.
- **You obviously know this system better than I do.** — معلوم است که تو این سیستم را بهتر از من می‌شناسی.
- **The plan obviously isn't working.** — واضح است که این برنامه جواب نمی‌دهد.
- **You obviously didn't read my message.** — معلوم است که پیامم را نخواندی. (ممکن است سرزنش‌آمیز باشد.)

## تفاوت با واژه‌های نزدیک

- **obviously** — روشن بودن چیزی از نگاه گوینده؛ می‌تواند قاطع و مستقیم شنیده شود.
- **clearly** — «به‌وضوح»؛ نزدیک است و گاهی خنثی‌تر یا مناسب توضیح منطقی است.
- **apparently** — «ظاهراً / طبق چیزی که فهمیده‌ام»؛ گوینده قطعیت کمتری دارد یا اطلاعات را از منبعی گرفته.
- **probably** — احتمال زیاد، نه آشکاربودن.
- **of course** — «البته / معلومه»؛ می‌تواند انتظار مشترک یا موافقت را نشان دهد و بسته به لحن کنایه‌آمیز شود.

## دام‌های رایج

- از **obviously** برای نکته‌ای که ممکن است برای شنونده واضح نباشد زیاد استفاده نکن؛ می‌تواند تحقیرآمیز به نظر برسد.
- برای پیشنهاد مؤدبانه، گاهی **It seems clear that ...** یا **From this, we can see ...** نرم‌تر است.
- اگر مطمئن نیستی، **apparently / probably / it seems** را بررسی کن.

## کدگذاری فارسی و قانون پنج‌ثانیه‌ای

- «واضح است / از نشانه‌ها معلوم است» → **obviously**
- «طبق اطلاعاتی که دارم، ظاهراً» → **apparently**
- «احتمال زیاد، اما نامطمئن» → **probably**

1. **تشخیص:** چیزی واقعاً برایت روشن است یا فقط حدس/گزارش است؟
2. **تصمیم:** روشن و قاطع → **obviously**؛ اطلاعات غیرمستقیم → **apparently**.
3. **اجرا:** ابتدای جمله برای ارزیابی کل حرف، یا در میانه برای تأکید.
4. **بررسی استثنا:** مخاطب را مقصر جلوه نمی‌دهد؟ اگر بله، واژه را حذف یا نرم‌تر کن.
