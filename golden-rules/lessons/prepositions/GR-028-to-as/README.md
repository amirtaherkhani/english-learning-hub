# GR-028 — TO / AS

**Category:** prepositions

## قانون طلایی — کد فارسی

> تغییر به وضعیت جدید → to؛ طبقه‌بندی یا علامت‌گذاری به‌عنوان → as

## مثال‌های روزمره

- **Set the status to Done.** — وضعیت را Done کن.
- **Mark it as completed.** — انجام‌شده علامت بزن.
- **Assign it to Sara.** — به سارا اختصاص بده.
- **Use it as a template.** — به‌عنوان قالب استفاده کن.

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## تمرین زنده

تمرین، پاسخ و نمره در مخزن ذخیره نمی‌شوند؛ Skill مربوطه آن‌ها را داخل چت تولید می‌کند.
