# GR-029 — AS AND ITS USES

**Category:** prepositions

## قانون طلایی — کد فارسی

> به‌عنوان → as؛ به اندازهٔ → as ... as؛ به محض اینکه → as soon as؛ تا جایی که → as far as

## مثال‌های روزمره

- **I work as an engineer.** — به‌عنوان مهندس کار می‌کنم.
- **It's as fast as mine.** — به سرعت مال من است.
- **I'll call as soon as I arrive.** — به محض رسیدن زنگ می‌زنم.
- **As far as I know, it's ready.** — تا جایی که می‌دانم آماده است.

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## تمرین زنده

تمرین، پاسخ و نمره در مخزن ذخیره نمی‌شوند؛ Skill مربوطه آن‌ها را داخل چت تولید می‌کند.
