# GR-015 — USED TO

- **Category:** verb-patterns
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> قبلاً عادت داشتم کاری کنم؛ حالا شرایط تغییر کرده → used to+V1

## فرمول

`used to+V1; didn't use to+V1; Did ... use to+V1?`

## مثال‌های واقعی

- **I used to smoke.** — قبلاً سیگار می‌کشیدم.
- **I used to live here.** — قبلاً اینجا زندگی می‌کردم.
- **Did you use to drive?** — قبلاً رانندگی می‌کردی؟
- **I didn't use to like tea.** — قبلاً چای دوست نداشتم.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
