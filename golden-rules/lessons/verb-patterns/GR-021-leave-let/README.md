# GR-021 — LEAVE / LET

**Category:** verb-patterns

## قانون طلایی — کد فارسی

> بگذار چیزی در حالتی بماند → leave + object + state؛ بگذار شخص کاری کند → let + person + V1

## مثال‌های روزمره

- **Leave the door open.** — در را باز بگذار.
- **Leave the light on.** — چراغ را روشن بگذار.
- **Let her speak.** — بگذار حرف بزند.
- **Leave it as it is.** — همان‌طور که هست بگذار.

## نکتهٔ ساختاری

ساختار فعل و حرف اضافه را با هم حفظ کن. شکل V1/V2/V3 و تفاوت میان معنی لغوی، اصطلاحی و زمان دستوری را از متن تشخیص بده. برای سؤال و منفی، از فعل کمکی مناسب استفاده کن.

## تمرین زنده

تمرین، پاسخ و نمره در مخزن ذخیره نمی‌شوند؛ Skill مربوطه آن‌ها را داخل چت تولید می‌کند.
