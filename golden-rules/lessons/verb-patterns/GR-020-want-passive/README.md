# GR-020 — WANT SOMETHING DONE

- **Category:** verb-patterns
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> می‌خواهم چیزی انجام شود → want+object+to be+V3؛ سرویس گرفتن → want to get+object+V3

## فرمول

`want+object+to be+V3; want to get+object+V3`

## مثال‌های واقعی

- **I want my car to be washed.** — می‌خواهم ماشینم شسته شود.
- **I want to get my car washed.** — می‌خواهم بدهم ماشینم را بشویند.
- **I want my phone repaired.** — می‌خواهم گوشیم تعمیر شود.
- **I want to clean it myself.** — می‌خواهم خودم تمیزش کنم.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
