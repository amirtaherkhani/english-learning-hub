# GR-016 — BE USED TO

- **Category:** verb-patterns
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> به انجام کاری عادت دارم → be used to+V-ing یا اسم

## فرمول

`be used to+V-ing/noun`

## مثال‌های واقعی

- **I'm used to waking up early.** — به زود بیدار شدن عادت دارم.
- **She's used to the cold.** — به سرما عادت دارد.
- **I was used to working nights.** — به شب‌کاری عادت داشتم.
- **Are you used to driving here?** — به رانندگی اینجا عادت داری؟

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
