# GR-017 — GET USED TO

- **Category:** verb-patterns
- **Level:** A2–B1 (indicative)

## قانون طلایی و کد فارسی

> دارم عادت می‌کنم → getting used to؛ عادت کردم → got used to

## فرمول

`get/got/getting used to+V-ing/noun`

## مثال‌های واقعی

- **I'm getting used to the weather.** — دارم به هوا عادت می‌کنم.
- **I got used to working early.** — به صبح‌کاری عادت کردم.
- **I'll get used to it.** — بهش عادت می‌کنم.
- **I haven't gotten used to it yet.** — هنوز عادت نکرده‌ام.

## دام‌ها و نکات

- ترجمهٔ کلمه‌به‌کلمهٔ فارسی همیشه ساختار طبیعی انگلیسی نمی‌دهد.
- زمان فعل و شکل V1/V2/V3 را با توجه به ساختار کامل جمله بررسی کن.
- هنگام کاربردهای نزدیک، معنی دقیق و بافت جمله را ملاک قرار بده.
