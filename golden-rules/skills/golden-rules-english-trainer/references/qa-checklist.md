# Lesson and quiz QA checklist

Run this review before presenting a Golden Rule lesson or exercise.

## Lesson

- [ ] The learner's requested topic is the only core focus.
- [ ] Topic title, level, grammatical category, difficulty, and objectives are stated when useful.
- [ ] A2 is the default; relevant A1/A2 concepts are covered and B1 is clearly supplementary.
- [ ] Topic classification and lesson structure are adapted; irrelevant sections are omitted.
- [ ] The rule is precise and does not turn a shortcut into an absolute.
- [ ] Strict rules, tendencies, context-dependent usage, and exceptions are distinguished when needed.
- [ ] Persian mental coding is a useful recognition clue, not an unconditional translation formula.
- [ ] Word class, position, inflection, tense, questions, and negatives are included only when relevant.
- [ ] Prerequisites are addressed only when helpful.
- [ ] Important exceptions and common mistakes have an explanation.
- [ ] Natural minimal pairs compare similar forms.
- [ ] The Five-Second Rule covers Recognize, Decide, Apply, and Exception Check.
- [ ] Examples are natural, correct, and paired with useful Persian meanings.
- [ ] Every English example is kept LTR; Persian explanation remains readable RTL.
- [ ] Lesson and practice are native chat content; no HTML or web app is created.
- [ ] There is no personal-notes section.

## Every exercise item

- [ ] Instruction, prompt, context, and every choice are English.
- [ ] The format is recognizable from a grammar coursebook.
- [ ] The selected exercise format tests the target concept.
- [ ] The item tests a taught point at the stated level.
- [ ] The intended answer is correct in both grammar and meaning.
- [ ] Each single-answer item has one answer only; alternatives have been considered.
- [ ] Context disambiguates words with more than one valid meaning.
- [ ] Punctuation, capitalization, and subject/verb context do not accidentally introduce another answer.
- [ ] The answer key is withheld until submission unless requested.
- [ ] Count, difficulty, and CEFR level match the request.
- [ ] Question contexts, answer positions, and concept coverage are varied.

## Interaction and feedback

- [ ] The active step is clear; the learner is not pushed ahead before responding.
- [ ] Hints do not reveal the answer prematurely.
- [ ] Progressive hints move from clue to rule to narrowed choices when used.
- [ ] Feedback uses red/green/yellow symbols plus text, not color alone.
- [ ] Every wrong answer includes the correction and a rule tailored to that error.
- [ ] Valid alternatives and partial answers are classified accurately.
- [ ] Valid alternatives are accepted and explained.
- [ ] Mastery claims are evidence-based; untested concepts remain untested.
- [ ] Persistent history and scheduled reviews are not claimed without actual support.
- [ ] Difficulty and set coverage match the request.
- [ ] Reset means same questions; New Set means new questions.
- [ ] No hidden storage, buttons, browser behavior, or cross-chat memory is claimed.
- [ ] The learner is not moved to a new topic before completing practice unless they ask.
- [ ] Responsive readability is considered; visual test claims match actual inspection.
