# Reusable lesson and quiz patterns

These are structural patterns, not fixed scripts. Adapt the relevant parts to the requested topic. Keep all exercise fields in English and keep generated questions and keys in the live conversation only.

## Lesson outline

```markdown
# Golden Rule — [English topic] / [موضوع فارسی]
**Core level:** A1–A2 · **Optional extension:** B1
**Category:** [relevant grammar categories]
**Difficulty:** [selected level]
**Learning goals:** [short, observable goals]

## قانون اصلی
[شرح دقیق فارسی؛ ساده‌ترین توضیح درست]

## کدگذاری فارسی
[نشانهٔ فارسی → ساختار انگلیسی؛ همراه با حد و استثنا]

## فرمول و کاربرد
[ساختار، جایگاه واژه، صورت‌های مرتبط و زمان‌ها فقط در صورت نیاز]

## مثال‌ها و مقایسه
[جفت‌های طبیعی انگلیسی؛ ترجمهٔ فارسی بیرون از تمرین]

## خطاها و استثناها
[خطا، شکل درست، دلیل، قانون طلایی مشخص]

## قانون پنج‌ثانیه‌ای
Recognize → Decide → Apply → Exception Check

## Guided check
[یک سؤال انگلیسی متناسب با قانون؛ در گفت‌وگوی زنده منتظر پاسخ بمان]
```

A learner-facing answer to a narrow question may omit irrelevant sections. Do not display the guided check or a practice batch if the learner requested explanation only.

## Exercise design checklist

- Select a familiar grammar-book format that tests the taught point.
- Write instructions, context, stems, and options in English.
- Use familiar vocabulary and an appropriate CEFR level.
- Include only enough context to identify the intended meaning.
- Solve the item before presenting it; test plausible alternatives and register.
- If another answer is valid, rewrite the item, ask for all valid answers, or accept each defensible response.
- Vary concepts, contexts, sentence forms, exercise types, and answer positions across fresh sets.
- Hide the answer key until submission unless the learner asks to see it.

## Feedback structure

```text
[Correctness label] — [brief status]
[Corrected English sentence, when needed]
[Short Persian explanation]
Golden Rule: [specific rule that addresses this error]
```

Use a clear text label with any symbol; never rely on color alone. Accept valid alternatives and explain their meaning or register differences.

## Text controls

Use `references/text_quiz.md` for text-only interaction. `Reset` repeats the same questions and clears the current grading; `New Set` creates fresh questions. These are chat commands, not promises of buttons or hidden application behavior.
